# Misskey インスタンスフィルター (Timeline Instance Filter)

これは Misskey 用に設計されたブラウザユーザースクリプト (Userscript) です。グローバルタイムライン (GTL)、ソーシャルタイムライン (STL)、アンテナ、チャンネルタイムラインを閲覧する際に、興味のあるインスタンス（サーバー）と言語の投稿だけを表示できます。

タイムラインに無関係な情報が多すぎると感じたり、特定のコミュニティの議論だけに集中したい場合に非常に便利です。独立してオン/オフできる 2 つのフィルタールールを提供します：

* **インスタンスホワイトリスト**：リストに追加したインスタンスの投稿だけを表示します。
* **言語フィルター**：自動検出した言語で投稿を残す／隠す（例：中国語だけ表示、英語を非表示）。

> **プライバシーを非常に重視するユーザーへの提案**（[プライバシーについて](#privacy)）：
> スクリプトがすべてのウェブサイトで実行されることを望まない場合、スクリプトマネージャー（Tampermonkeyなど）の設定ページで、「ユーザーマッチ (User Matches)」を手動で常用している Misskey
> インスタンスのドメインに変更することができます。ただし、これにより新しいインスタンスを自動的に識別する機能は失われます。

## ✨ 主な機能

* **インスタンスホワイトリストフィルタリング**: 手動でリストに追加したインスタンスのコンテンツのみが表示されます（いつでもオン/オフ可能）。
* **言語フィルター**: 投稿の言語を自動検出し、「選択した言語のみ表示」と「選択した言語を非表示」の 2 つのモードに対応（いつでもオン/オフ可能）。言語コードは `zh ja en`、`中文 日语`、`jpn`、`zh-CN` などの書き方に対応します。
* **2 つの検出エンジンを切り替え可能**:
    * `tinyld light`（デフォルト、約 70KB、24 言語）
    * `efficient-language-detector`（eld XS、約 940KB、60 言語。ベトナム語・ウクライナ語なども含む）
* **フィルター範囲を選択可能**: ホーム、パブリック（ローカル/ソーシャル/グローバル）、リスト、アンテナ、チャンネル、ロール、探索を個別にオン/オフできます。リアルタイム配信（WebSocket）も同じ選択に従います。
* **ローカルコンテンツを非表示**: 独立したスイッチで、現在閲覧しているインスタンス（ローカル）の投稿を非表示にし、外部インスタンスの探索に集中できます。
* **スマートページ読み込み**: ページ内のすべてのコンテンツがフィルターで除外された場合、条件に合う投稿が見つかるか、設定された上限（最大10ページ）に達するまで、スクリプトが自動的に次のページを読み込みます。
* **最近ブロックされたリスト & リアルタイム連動**:
    * スクリプトは、最近ブロック（非表示に）されたインスタンスのドメインを自動的に記録します。
    * **リアルタイムフィードバック**：ホワイトリストの編集ボックスにドメインを入力すると、下のブロックリストがリアルタイムで更新され、ホワイトリストに追加済みのドメインは自動的に削除されます。
* **ワイルドカード検索**: 「最近ブロックされたリスト」内での検索に `*` ワイルドカード（例：`*.jp`）を使用できます。
* **多言語サポート**: インターフェースは簡体字中国語、日本語、英語に対応しており、ブラウザの言語設定を自動的に検出します。
* **軽量設計**: 言語フィルターが無効なときは検出ライブラリを一切読み込みません。Misskey インスタンスを認識したときのみ動作します。

## ⚙️ オプション説明

**インスタンスホワイトリスト**

* **ホワイトリストスイッチ**: オフにするとインスタンスのフィルタリングを一切行いません（リストの内容は保持されます）。
* **インスタンスホワイトリスト**: ドメインを1行に1つずつ入力します（例：`misskey.io`）。
* **最近ブロックされたインスタンス**: 最近非表示にされた投稿元を表示します。**「追加 +」** をクリックすると、そのインスタンスを素早くホワイトリストに追加できます。

**言語フィルター**

* **言語フィルタースイッチ**: オフにすると言語検出を一切行いません（検出ライブラリも読み込まれません）。
* **モード**: 「選択した言語のみ」または「選択した言語を非表示」。
* **検出エンジン**: `tinyld light`（24 言語）または `eld XS`（60 言語）。対応言語は選択欄の下に表示されます。
* **言語リスト**: スペースまたはカンマ区切り。言語を判別できない投稿（絵文字のみ、極端に短いテキストなど）は誤判定を避けるため残します。

**フィルター範囲**

* フィルターする入口を選択します：ホーム、パブリック、リスト、アンテナ、チャンネル、ロール、探索。既定ではすべてオンです。オフにした入口は一切傍受されません（レスポンスの解析も行いません）。

**その他**

* **ローカルコンテンツを非表示**: ホワイトリストスイッチとは独立して動作します。
    * **オフ（デフォルト）**：現在のインスタンスのコンテンツ ＋ ホワイトリストのインスタンスコンテンツを表示します。
    * **オン**：すべてのローカル投稿を非表示にし、ホワイトリストにあるリモートインスタンスのコンテンツのみを表示します。
* **自動読み込みページ上限**: コンテンツが少ない場合に、スクリプトが連続して自動取得する最大ページ数を設定します（0-10）。
* **デバッグモード**: オンにすると、ブラウザのコンソール（F12）で詳細なフィルタリングログを確認できます。

## 🛡️ 権限とプライバシーについて

### なぜ「すべてのウェブサイトへのアクセス」権限が必要なのですか？

Misskey インスタンスは何千もの異なるドメインに分散しているため、スクリプトはWebページのヘッダーにある `meta` タグを読み取って、現在のサイトが Misskey であるかどうかを確認する必要があります。

1. **静的検出**: スクリプトはページ読み込み時に一度だけ検出を行います。現在のサイトが Misskey でない場合、スクリプトは即座に動作を完全に停止します。
2. **言語検出はすべてローカル**: 言語判定はブラウザ内で完結し、投稿テキストが外部に送信されることはありません。検出ライブラリのファイルのみ、インストール／更新時にユーザースクリプトマネージャーが公共 CDN（jsDelivr / unpkg）から一度ダウンロードし、ローカルにキャッシュします。
3. **データアップロードなし**: すべてのフィルタリングロジックとホワイトリストデータはブラウザのローカル（`GM_setValue`）に保存され、閲覧履歴や個人情報をサーバーにアップロードすることは**決してありません**。
4. **完全オープンソース**: GitHub 上でいつでもこのスクリプトのソースコードを確認・監査することができます。

## ❓ よくある質問 (FAQ)

**Q: 「インスタンス」とは何ですか？**
A: Misskey は分散型ソーシャルネットワークであり、多くの独立したサーバー（Webサイト）で構成されています。これらのサーバーを「インスタンス」と呼びます。ユーザーは異なるインスタンスに登録できますが、相互に交流することが可能です。グローバルタイムライン（GTL）には、様々なインスタンスからの公開投稿が表示されます。

**Q: このスクリプトはフォローしている人の投稿に影響しますか？**
A: 既定では影響します。「フィルター範囲」はホーム（フォロー中）タイムラインを含むすべての入口がオンになっています。パブリックタイムラインやアンテナだけをフィルターしたい場合は、設定で該当項目のチェックを外してください。ユーザーのプロフィール、検索結果、通知（メンション）、クリップはフィルターされません。

**Q: ホワイトリストを追加しましたが、タイムラインの投稿が減った気がします。**
A: それは正常な動作です。スクリプトがホワイトリストにないすべてのインスタンスのコンテンツを除外しているためです。コンテンツが少なすぎると感じる場合は、「最近ブロックされたインスタンス」機能を使って、興味のあるインスタンスを見つけてホワイトリストに追加してみてください。

**Q: 言語検出で投稿内容が外部に送信されますか？**
A: いいえ。検出はすべてブラウザ内で実行されます（`tinyld` と `eld` はいずれも純粋な JavaScript 実装です）。外部への通信は、インストール／更新時に検出ライブラリのファイルを CDN から一度ダウンロードするときだけです。

**Q: 「中国語のみ」にしているのに、外国語の投稿が表示されることがあります。**
A: 言語を判別できなかった投稿（絵文字のみ、数字のみ、極端に短いテキストなど）は誤判定を避けるため残す仕様です。また、検出に失敗した場合は Misskey の `lang` フィールドをフォールバックとして使用します。

**Q: 2 つの検出エンジンはどう違いますか？**
A: `tinyld light` は軽量（約 70KB）ですが 24 言語のみ、`eld XS` は大きい（約 940KB）ですが 60 言語に対応します。ベトナム語やウクライナ語でフィルターしたい場合は `eld XS` を選んでください。なお、選択したエンジンが対応していない言語でフィルターすると、その言語の投稿が別の言語と誤判定されることがあります。

**Q: 検出ライブラリのダウンロードに失敗しました。**
A: 設定パネルの言語フィルター欄にライブラリの状態が表示されます。**「再ダウンロード」** をクリックすると予備 CDN（jsDelivr / unpkg / GitHub）から再試行し、成功すると自動的にページが再読み込みされます。

**Q: このスクリプトを一時的に無効にすることはできますか？**
A: はい。ブラウザの Tampermonkey 拡張機能メニューから、インストール済みスクリプトのリストを開き、そこで「Misskey Instance Filter」を一時的にオフにすることができます。
